# PhD Project 1

Research code for hybrid ERNN and QRNN models for cryptocurrency tail-risk forecasting.

The notebooks cover:

- Bitcoin data preprocessing
- Hybrid ERNN and QRNN specifications
- Symmetric, asymmetric and self-interaction models
- Self-lagged and cross-lagged structures
- Methods for addressing quantile and expectile crossover
- Hyperparameter tuning and out-of-sample evaluation

This is a private research repository. Reproducing the results may require the original datasets and Python environment.
